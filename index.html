SQL you can inspect

Turn evidence into queryable information.

The Fraud Lab uses Python and SQLite to generate and analyze 3,771 synthetic transactions across 60 accounts. The Adverse Media Review Desk runs on SQLite / Cloudflare D1 with nine training cases and 27 evidence comparisons.

  • JOINs and foreign keys connect evidence to the right case.
  • CTEs and CASE make the triage rules inspectable.
  • GROUP BY and COUNT summarize matches, conflicts and missing identifiers.
  • JSON extraction and migrations read source attributes and maintain the schema.

How I work

The investigation comes first.

A match is a lead

A matching name starts the review. It doesn't conclude it. I compare identifiers before drawing a line between two parties.

Missing ≠ mismatch

Unknown information stays unknown. Every tool separates confirmed evidence, conflicts and open questions.

Built for the next reviewer

Rationale, alternative explanations and a clear handoff to QC, so someone else can check the decision.

I use AI-assisted development to turn AML workflow ideas into tools you can inspect. Each project documents its scope and limits, and none makes an automatic finding of wrongdoing.
