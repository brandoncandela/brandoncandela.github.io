Adverse Media Review Desk

Decides whether a news story is really about your customer, with the same triage rules written in TypeScript for analysts and SQL for auditors.

Who it is for

KYC and screening analysts reviewing negative news hits, and the QC teams who check them.

What I built

A side-by-side identifier comparison, news search, triage rules in TypeScript and a SQL view, and an export pipeline that runs the SQL migrations.

Result

The interface and the SQL view reach the same outcome, and a query proves it by returning nothing when they agree.

The problem

Name screening finds articles that mention someone with your customer's name. Most are about someone else. The common mistake is treating missing information as a mismatch, which closes alerts that were never actually cleared.

Architecture

How data moves from source to decision.

  1. CompareBank record and article subject side by side: match, variant, conflict or unknown.
  2. Search newsGDELT news search, a Google search link, or a manual article.
  3. Triage in codeRules in lib/matching.ts drive the interface.
  4. Triage in SQLMigrations build 9 cases and a view using a CTE, CASE, conditional aggregation and JSON extraction.
  5. ExportA script runs the migrations in SQLite and exports the SQL-derived outcomes.
  6. DecideEscalate, rule out or request information, with the reasoning saved.

Engineering decisions

Four states instead of match or no match

Only a verified conflict counts against a hit; unknown stays an evidence gap.

Two implementations, one answer

The SQL view and the TypeScript rules are checked against the expected outcome so they cannot drift apart unnoticed.

Location alone never rules a hit out

People move. A name and full date of birth match escalates even if the city differs.

Tests

20 node:test cases, run with one command and no network.

  • A missing middle name or unknown identifier is never a mismatch
  • An unverified DOB conflict is not a false positive; a verified one needs evidence and a source
  • Name and full DOB escalate despite a country conflict
  • Day-month reversals are ambiguous, and age is judged on the article date
  • Unsafe links are rejected and stale QC is flagged after a customer change

Results

  • Nine training cases that each test a tricky situation
  • A disagreement query between SQL and expected outcomes that returns zero rows

Limitations

  • Training cases are fictional
  • News search depends on GDELT coverage
  • The full case store in data-model.sql is a design proposal, not used by the demo
